Docs ビューアー

`docs/` 配下の資料をブラウザで素早く整理・閲覧できる Laravel プラグインです。orbit-ops の `/dev/docs` 画面をパッケージ化し、`composer require` だけで導入できます。

Packagist GitHub README

特徴

ドキュメント自動一覧

`docs/` 配下をカテゴリごとに自動スキャンし、設計書・Development などをカード表示。README へのクイックリンクも付属。

  • Markdown を安全に HTML 化
  • README 例外パスも指定可能
  • パスからルートへ自動リンク

環境に合わせて柔軟

.env でルート prefix、middleware、レイアウト、ダッシュボードへの戻り先などを切替。ロケールも `?lang=` で即変更。

  • 可変 root ディレクトリ
  • App/Development グループを設定
  • ロケール既定値を `.env` で

プロダクトに寄り添う UI

デフォルトの Blade レイアウトを同梱しつつ、`vendor:publish` でビューを配布可能。アプリ共通レイアウトへの置換も容易。

  • ダーク基調のシンプル UI
  • コピー/折りたたみなど実用機能
  • Vite バンドル対応

セットアップ

  • 1
    インストール
    composer require orbit-sys-dev/laravel-dev-docs-viewer
  • 2
    publish
    php artisan vendor:publish --tag=docs-viewer-config
    php artisan vendor:publish --tag=docs-viewer-views
  • 3
    .env に最低限の設定
    DOCS_VIEWER_ROUTE_PREFIX=dev/docs
    DOCS_VIEWER_LOCALE=ja
    DOCS_VIEWER_AVAILABLE_LOCALES=ja,en
  • 4
    動作確認
    php artisan serve
    https://localhost:8000/dev/docs?lang=ja
